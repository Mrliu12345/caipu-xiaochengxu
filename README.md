
# 今天吃什么 · 菜谱小程序

一个极简的微信小程序：首页按分类展示菜谱（真实美食封面图），点进详情可看所需材料、调料、火候、时间与分步做法。

## 当前规模

- **菜谱总数**：80 道
- **分类**：全部 / 快手菜(18) / 硬菜(36) / 主食(10) / 汤类(9) / 河南风味(7) / 我的收藏
- **封面**：80 张写实美食摄影图（jpg，360×270，每张约 12-21KB），全部本地打包，**无需服务器、无需域名、无任何网络请求**

## 功能

- **搜索**：首页顶部输入菜名关键词（如"鸡""豆腐""辣"）实时过滤
- **随便吃点啥**：首页橙色按钮，一键随机推荐一道菜
- **收藏**：详情页点「☆ 收藏」存到本地缓存，底部导航栏「收藏」页统一存放；再点一次取消
- **分享**：首页/详情页右上角转发，转发卡片带菜名（个人小程序主要靠分享传播）

## 怎么运行

1. 电脑安装「微信开发者工具」（微信公众平台官网免费下载：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html）
2. 打开工具 → 点「导入项目」→ 目录选择本文件夹：`D:\菜谱小程序`
3. AppID 选择「测试号」（已默认配置为 touristappid），点确定
4. 编译后即可在模拟器预览；点「预览」可生成二维码，手机微信扫码真机体验

> 发布正式版时：用免费的个人主体小程序账号登录 mp.weixin.qq.com，把 AppID 换成自己的即可，全程无需配置服务器域名（本程序零网络请求）。

## 怎么改菜谱

所有菜谱都在 `data/recipes.js` 里，每个菜谱是一个对象：

```js
{
  id: 9,                  // 编号，不能重复
  name: '菜名',
  cover: '/assets/images/recipe_09.webp',  // 封面图路径（assets/images 下，按 id 命名）
  bg: '#FF7043',          // 兜底背景色（图片加载失败时显示）
  desc: '一句话简介',
  time: '10分钟',          // 总耗时
  difficulty: '简单',      // 难度：简单 / 中等 / 困难
  type: '快手菜',          // 分类：快手菜 / 硬菜 / 主食 / 汤类 / 河南风味
  ingredients: ['材料 1', '材料 2'],   // 所需材料
  seasonings: ['盐', '油'],           // 调料
  steps: [                // 做法步骤：每一步的火候和时间
    { op: '第一步做什么', fire: '大火', time: '2分钟' },
    { op: '第二步做什么', fire: '小火', time: '5分钟' }
  ]
}
```

### 添加一道新菜

1. 复制一个对象，改内容，`id` 换成下一个数字（如 81）
2. 准备封面图：生成/找一张该菜的写实照片，压缩为 `assets/images/recipe_81.webp`（建议 480×360，单张 ≤30KB 以控制包体积）
3. `cover` 填 `/assets/images/recipe_81.webp`，保存后首页和详情页自动显示

### 包体积提醒

微信小程序主包上限 2MB。当前主包约 1.82MB（代码 76KB + 封面 1.74MB）。再加菜时请保持每张封面 ≤30KB（用 webp 格式，尺寸 480×360），否则容易超限。
